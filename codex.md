🌐 API

Endpoint

GET /like

Request Format

/like?uid={UID}&server_name={SERVER}&key={KEY}

Example

/like?uid=123456789&server_name=bd&key=ZORO


---

📌 Parameters

Parameter	Required	Description

uid	✅	Target UID
server_name	✅	Server code
key	✅	API access key
